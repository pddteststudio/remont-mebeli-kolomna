# Ремонт мебели — Коломна, Воскресенск, Раменское

**Демонстрационный сайт мастерской по ремонту и перетяжке мягкой мебели.** Разработан как предложение владельцу, не является официальным сайтом мастерской.

## Как открыть сайт

1. Распакуйте архив.
2. Для полноценной работы сайта откройте `index.html` в обычном браузере или разместите проект на статическом хостинге.
3. Автономные файлы `preview-offline.html`, `preview-works-offline.html`, `preview-fabrics-offline.html` и `preview-estimate-offline.html` содержат встроенные иллюстрации, стили и JavaScript для самостоятельного просмотра каждой страницы. Для корректной навигации между страницами используйте стандартные `index.html`, `works.html`, `fabrics.html` и `estimate.html`.

## Как опубликовать на Vercel

1. Загрузите **содержимое** этой папки в репозиторий GitHub (чтобы `index.html` лежал в корне репозитория).
2. Подключите репозиторий в Vercel через **Add New → Project**.
3. Выберите **Framework Preset: Other**. Build Command и Output Directory не нужны — проект является статическим.
4. Нажмите **Deploy** и откройте полученный URL.
5. Для коммерческой публикации сначала согласуйте тексты, фотографии и условия с мастерской, а затем удалите мета-тег `noindex` и демонстрационные подписи по разрешению владельца.

## Состав

- `index.html` — главная страница: услуги, сравнение "до/после", истории, этапы работы, FAQ и контакты.
- `works.html` — шесть опубликованных историй, фильтры по предметам, карточки с подробностями.
- `fabrics.html` — образцы шести типов материалов. При выборе передаётся соответствующий параметр в форму оценки.
- `estimate.html` — выбор предмета мебели, вида ремонта, ширины, города и ткани; до трёх фотографий (каждая до 8 МБ; JPG, PNG, WebP); готовый текст заявки и ссылки на VK.
- `assets/style.css`, `assets/app.js`, `assets/data.js` — стили, сценарии и данные проектов.
- `assets/scenes/*.svg` — 14 оригинальных интерьерных SVG. **Не являются фотографиями реальных работ.**
- `previews/` — скриншоты и `qa.json` с результатами проверок.
- `СООБЩЕНИЕ_ДЛЯ_VK.txt` — шаблон первого обращения владельцу.

## Важно о функциональности

Копирование текста заявки работает в современных браузерах. Если браузер запрещает доступ к буферу обмена, поле текста выделяется для ручного копирования.

Фотографии остаются только на устройстве посетителя, НЕ отправляются на сервер и НЕ прикрепляются автоматически к диалогу VK. Клиент должен самостоятельно прикрепить их в чате после перехода по кнопке. Мы не заявляем, что заказ отправлен, пока пользователь сам этого не сделал.
